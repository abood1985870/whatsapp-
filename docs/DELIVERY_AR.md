## ⚠️ خطوة إجبارية واحدة قبل التسليم

النظام كامل ويعمل، **ما عدا مفتاح OpenAI** — بدونه لن يرد الذكاء الاصطناعي.

1. افتح ملف `.env` في مجلد المشروع
2. عدّل السطر:
   ```
   OPENAI_API_KEY=sk-ضع-المفتاح-الحقيقي-هنا
   ```
3. أعد تشغيل النظام:
   - شغّل `scripts\stop-qanoai.cmd`
   - ثم `scripts\start-qanoai.cmd`

تم اختبار السلسلة كاملة: رسالة واردة ← جهة اتصال ← محادثة ← مهمة ذكاء اصطناعي ← استدعاء OpenAI.
الفشل الوحيد المسجل كان "مفتاح API غير صحيح" — أي أن كل ما قبل المفتاح يعمل.

## خطوات العرض عند العميل (Demo Script)

1. **تسجيل الدخول**: `http://localhost:3000` — `owner@demo.qanoai` / `DemoPass123!`
   (أو سجّل حساباً جديداً — التسجيل يعمل وينشئ مؤسسة كاملة)
2. **ربط واتساب**: صفحة "واتساب" ← الاتصال الجاهز "واتساب الدعم" ← اعرض QR
   ← امسحه من الجوال (الإعدادات ← الأجهزة المرتبطة ← ربط جهاز)
3. **إعداد الوكيل الذكي**: صفحة "وكلاء الذكاء الاصطناعي" ← الإعدادات
   ← اكتب تعليمات الوكيل ← "حفظ ونشر"
4. **اختبار فوري**: زر "اختبار" ← اكتب سؤال عميل ← شاهد القرار والرد والثقة
5. **إضافة معرفة**: صفحة "قاعدة المعرفة":
   - أسئلة شائعة (FAQ) — يقرأها الوكيل مباشرة
   - أو "إضافة مستند" داخل قاعدة معرفة — يُقطَّع ويُفهرَس تلقائياً (بحث دلالي pgvector)
6. **التجربة الحية**: أرسل رسالة واتساب من رقم آخر للرقم المربوط
   ← تظهر فورياً في صندوق الوارد ← يرد الذكاء الاصطناعي تلقائياً
7. **تدخل بشري**: من المحادثة: بدّل الوضع إلى "بشري فقط" ← اكتب رد يدوي ← يصل للعميل
8. **إجراءات المحادثة**: إنهاء / إعادة فتح / تعيين لي / حظر — كلها تعمل
9. **التحليلات**: صفحة "التحليلات" — مؤشرات حقيقية + رسمان بيانيان لآخر 7 أيام + تصدير CSV
10. **الإعدادات**: تعديل اسم المؤسسة، تغيير كلمة المرور — تعمل فعلياً

## ما تم إصلاحه في هذه الجولة (ملخص تقني)

- سلسلة الرد الآلي كانت مقطوعة بالكامل (الويب هوك لا يستدعي الذكاء الاصطناعي) — أُصلحت واختُبرت
- ربط QR كان معطلاً بالكامل (4 أخطاء متراكمة: حاوية Evolution منهارة، حقل integration ناقص،
  نظام الصلاحيات يرفض الجميع، الويب هوك لا يُربط) — أُصلحت واختُبرت حية
- رد الموظف كان يُرسل لمعرّف قاعدة البيانات بدل رقم الهاتف — أُصلح
- البحث في قاعدة المعرفة كان وهمياً (رقم عشوائي) — الآن pgvector حقيقي
- معالجة المستندات لم تكن تعمل إطلاقاً — الآن تقطيع وتضمين حقيقي
- التحديثات الفورية (Socket.IO) لم يكن يبثها أحد — الآن مربوطة من كل المسارات
- حواجز أمان AI: حد إجراءات، حد معدل، فحص محتوى، كشف "أريد موظف"، ساعات عمل، كشف لغة
- المهام الدورية (تنظيف/تجميع استخدام) لم يكن لها مشغّل — الآن مجدولة تلقائياً
- ثغرة تسريب بيانات بين المؤسسات في أدوات الوكلاء — أُغلقت
- عزل المستأجر في إرسال الرسائل (كان يقبل organizationId من العميل) — أُصلح

كل إصلاح موثق بـ commit منفصل في git — راجع `git log`.

## حدود معروفة (كن صريحاً مع العميل)

| الميزة | الحالة |
|---|---|
| رسائل الوسائط (صور/ملفات) واردة | لا تُعالج — الرسائل النصية فقط حالياً |
| رفع PDF/Word لقاعدة المعرفة | غير متاح — الصق المحتوى كنص (الاستخراج قادم) |
| الفوترة والاشتراكات | غير مبنية (الجداول جاهزة، لا يوجد API/واجهة) |
| لوحة Super Admin | غير مبنية |
| استبيانات رضا العملاء (CSAT) | غير مبنية |
| مفاتيح API للربط البرمجي | غير متاحة (Swagger متاح للتجربة على /api/docs) |
| الاختبارات الآلية | غير مكتوبة بعد |
| QR واتساب | يعتمد على Evolution API (غير رسمي من Meta) — قد يحتاج إعادة ربط دورية |
| ساعات العمل | تُحسب بتوقيت الخادم المحلي، ليس بتوقيت كل مؤسسة |

## أوامر التشغيل

```
scripts\start-qanoai.cmd    التشغيل الكامل (Docker + الخدمات الأربع)
scripts\stop-qanoai.cmd     الإيقاف
scripts\status-qanoai.cmd   فحص الحالة
scripts\backup-db.cmd       نسخة احتياطية لقاعدة البيانات
```

| الخدمة | الرابط |
|---|---|
| الواجهة | http://localhost:3000 |
| API + Swagger | http://localhost:3001/api/docs |
| Realtime | http://localhost:3002 |
| Evolution (واتساب) | http://localhost:8080 |
